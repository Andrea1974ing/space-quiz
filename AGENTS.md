# Project instructions

- Keep the quiz as a single self-contained `index.html`; do not add a server, build step, or dependencies.
- Stay stringly typed: use plain JavaScript, strings, and DOM APIs rather than introducing a type system or schema layer.
- Preserve the existing responsive design, accessibility, reduced-motion behavior, and `prefers-color-scheme` support.
- Keep changes focused on the quiz and validate interactive behavior in the integrated browser when practical.
